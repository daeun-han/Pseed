## 📍 서비스 개요
Pseed는 특정 장소 방문 후 리뷰를 작성하는 일상적인 행위를 기부와 연결하여, 누구나 쉽고 간편하게 사회에 기여할 수 있도록 돕는 서비스입니다. 쇼핑몰 모델과 기부 프로세스를 결합하여 가치 소비와 나눔의 선순환 구조를 제공합니다.
